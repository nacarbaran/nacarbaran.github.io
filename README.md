# Nacar Publisher Infrastructure

This repository hosts public, machine-readable publisher verification files for mobile applications released by **Nacar**.

## Published files

- [`app-ads.txt`](https://nacarbaran.github.io/app-ads.txt) — authorized digital advertising sellers used to verify Nacar's mobile app inventory.

## Redirects for retired pages

`smeltara/` and `uclu/` forward the old Smeltara and Üçlü legal and support addresses (their own
GitHub Pages sites, now private repositories) to https://apps.barannacar.com, where those pages
live since 2026-10-28. Older app versions and the Google sign-in branding still open these
addresses, so keep these files while this site is online.

## Scope and security

This repository intentionally contains no application source code, credentials, private keys, user data, or confidential business information. Seller and publisher identifiers in `app-ads.txt` are public verification records intended to be crawled by advertising platforms.

The deployed site is minimal, static, and tracking-free: [nacarbaran.github.io](https://nacarbaran.github.io/).
